# ローカルグラフィックスエンジン 設計書

Singular Live を置き換え、テロップの描画・送出をアプリ内で完結させる機能の設計。

- 最終出力: **HTML5グラフィックス** (vMixのブラウザ入力で取り込み、1920x1080・透過背景)
- **2言語別々のURL出力** (JP / EN)
- 座布団画像・文字のサイズ/位置/フォント/レイアウト/デザインを **Photoshop風エディタ** で編集
- IN/OUTアニメーションは **プリセット選択+パラメータ調整** 方式
- Singular Live連携は**完全置き換え** (関連コード・設定は削除)

## 1. 全体アーキテクチャ

```
GMO TelopGo (Electron)
│
├─ 送出制御UI (既存)                     ├─ デザインエディタ (新規タブ)
│   スケジュール / かるた / GPIO / 2台連携  │   レイヤー編集・アニメ設定・試写
│         │                            │         │
│         ▼ TAKE/CHANGE/CLEAR           ▼ テンプレート保存
│   ┌─────────────────────────────────────────┐
│   │ グラフィックスエンジン (メインプロセス)          │
│   │  - プロジェクト(テンプレJSON+素材)管理        │
│   │  - リージョン状態管理 (name/side × jp/en)    │
│   │  - HTTP+WebSocketサーバ (ポート任意)        │
│   └─────────────────────────────────────────┘
│                     │ HTTP/WS (LAN)
│                     ▼
│   vMix ブラウザ入力 (1920x1080, 透過)
│     http://<PC>:<port>/output/jp   ← 日本語出力
│     http://<PC>:<port>/output/en   ← 英語出力
```

**WYSIWYGの担保**: エディタのアートボードと出力ページは**同一のレンダラー実装**(共通JS)を使う。
編集画面で見えるもの = vMixに出るもの。

## 2. 出力サーバ

Electronメインプロセスで `http` + `ws` (導入済み) により実装。ポートは設定で任意指定 (既定 8790)。

### URL構成

結合出力と分割出力を**常時両方提供**する (モード切替は不要で、vMix側でどのURLを取り込むかで運用を選ぶ)。

| URL | 内容 |
|---|---|
| `/output/jp` | 日本語: 名前テロップ+サイドテロップを1枚に重ねた出力 (基本運用・計2ソース) |
| `/output/en` | 英語: 同上 |
| `/output/jp/name` `/output/jp/side` `/output/en/name` `/output/en/side` | テロップ種別ごとの分割出力 (ミキサー側で個別制御したい場合・計4ソース) |
| `/assets/<file>` | 座布団などの画像素材 |
| `/fonts/<file>` | 持ち込みフォント (@font-face配信) |
| `/ws` | 状態配信WebSocket |

### WebSocketプロトコル (サーバ→出力ページ)

| type | ペイロード | 意味 |
|---|---|---|
| `init` | プロジェクト全体+現在のオンエア状態 | 接続/再接続時の初期化。**vMixがページを再読込しても表示が復元される** |
| `take` | `{region, templateKey, values}` | INアニメーションを再生して表示 (values = 全言語分のテキスト) |
| `change` | `{region, values}` | オンエア中の内容をライブ差し替え (非表示時は何もしない) |
| `clear` | `{region}` | OUTアニメーションを再生して消去 |
| `refresh` | プロジェクト全体 | エディタ保存時のテンプレート再読込 |

出力ページ→サーバは接続時の `hello {lang, region}` のみ (自身の担当を申告し、以後は受信専用)。

### 送出セマンティクス (現行UIをそのまま維持)

- **TAKE**: NEXTの内容で `take` を配信。ショットタイプが変わる場合は旧テンプレの `clear` (OUT) → 新テンプレの `take` (IN)
- **CHANGE**: オンエア中ならライブ差し替え。JP/ENの出力ページへ同時配信 (各ページは自分の言語のフィールドだけを表示)
- **CLEAR**: OUT再生
- name / side はリージョンとして独立制御 (同時オンエア可)

## 3. データモデル (プロジェクトファイル)

テンプレートと素材を「グラフィックスプロジェクト」として保存する。
保存先: `userData/graphics/project.json` + `userData/graphics/assets/` (画像/フォントの実ファイル)。
エクスポート/インポート (zip) で他PCへ持ち運び可能にする。

```jsonc
{
  "version": 1,
  "canvas": { "width": 1920, "height": 1080 },
  "assets": {
    "images": [{ "id": "img_zabuton", "file": "zabuton.png" }],
    "fonts":  [{ "id": "font_main", "family": "MyGothic", "file": "MyGothic.otf" }]
  },
  "templates": {
    // ショットタイプごと (nameOnly / 1S / 2S / 3S / 4S) + side
    "name-1S": {
      "region": "name",
      "variants": {
        "jp": {   // 言語ごとに独立したレイアウトを持つ
          "layers": [
            { "id": "ly1", "name": "座布団", "type": "image", "assetId": "img_zabuton",
              "x": 120, "y": 860, "w": 900, "h": 140,
              "opacity": 1, "rotation": 0, "visible": true, "locked": false },
            { "id": "ly2", "name": "肩書", "type": "text",
              "binding": "titleJp",            // 送出データのフィールドに結びつく
              "sample": "代表取締役",           // エディタ表示用サンプル
              "x": 160, "y": 872, "w": 320, "h": 40,
              "align": "left", "vAlign": "middle",
              "autoFit": "condense",           // none | shrink(縮小) | condense(長体)
              "font": { "family": "Noto Sans JP", "size": 30, "weight": 700,
                        "color": "#ffffff", "letterSpacing": 0.04, "lineHeight": 1.2 },
              "stroke": { "width": 0, "color": "#000000" },
              "shadow": { "x": 2, "y": 2, "blur": 6, "color": "rgba(0,0,0,0.6)" } }
          ],
          "animation": {
            "in":  { "preset": "slide", "direction": "up", "distance": 60,
                     "duration": 500, "easing": "ease-out", "stagger": 80 },
            "out": { "preset": "fade", "duration": 300, "easing": "ease-in" }
          }
        },
        "en": { /* 同構造。ENは別レイアウト/別フォント設定可 */ }
      }
    },
    "side": { "region": "side", "variants": { "jp": {}, "en": {} } }
  }
}
```

- レイヤー種別: `image` (座布団等のPNG/透過対応)、`text` (フィールドバインド)、`rect` (単色/グラデ/角丸の矩形座布団 — 画像なしでも作れる)
- 現行の「フィールドマッピング」設定は **テキストレイヤーのbinding** に置き換わる (titleJp/nameJp/2ndTitleJp/…/textJp/textEn)
- `autoFit`: 名前が長い場合の自動調整。`shrink`=フォント縮小 / `condense`=長体 (横方向scaleX圧縮、放送テロップの定番)

## 4. アニメーションエンジン

Web Animations API (WAAPI) ベース。**プリセット選択+パラメータ調整**方式。

| プリセット | 主なパラメータ |
|---|---|
| カット | なし |
| フェード | duration / easing |
| スライド | 方向(上下左右) / 距離 / duration / easing |
| ワイプ | 方向 / duration / easing (clip-pathマスクで座布団から拭き出し) |
| ポップ | 開始スケール / duration / バウンス強度 |
| ブラー | ブラー量 / duration |
| 文字送り | 1文字ごとのdelay (テキストレイヤーのみ) |

- **stagger** (レイヤー順次ディレイ) で「座布団→肩書→名前」の順出しを表現
- 将来拡張: レイヤー個別にIN/OUTを上書き設定 (v1はテンプレート単位+stagger)
- easing: ease / ease-out / ease-in-out / cubic-bezier プリセット数種

## 5. デザインエディタ (新規「デザイン」タブ)

```
┌──────────────────────────────────────────────────────────┐
│ テンプレ:[1S ▼] 言語:[JP|EN] ズーム:[50%▼] ▶IN試写 ▶OUT試写 [保存] │
├──────────┬────────────────────────────┬──────────────────┤
│ レイヤー    │        アートボード           │ プロパティ          │
│ ☰ 名前     │  1920x1080 / 市松模様=透過    │ X/Y/W/H/回転/不透明 │
│ ☰ 肩書     │  クリック選択・ドラッグ移動      │ [テキスト]          │
│ ☰ 座布団   │  8方向リサイズハンドル          │  バインド/フォント    │
│ ─────────  │  スナップ (中央/端/他レイヤー)  │  サイズ/色/縁取/影   │
│ [+文字]    │  矢印キーで1px移動            │  揃え/自動縮小       │
│ [+画像]    │  (Shiftで10px)              │ [アニメーション]      │
│ [+矩形]    │                            │  IN/OUTプリセット     │
└──────────┴────────────────────────────┴──────────────────┘
```

- **レイヤーパネル**: ドラッグで重ね順変更、表示/非表示、ロック、複製、削除
- **アートボード**: CSS transformでズーム (25〜200%)。サンプルデータでの実寸プレビュー。試写ボタンでIN/OUTアニメーションを再生
- **プロパティパネル**: 数値入力とドラッグの双方向。テキストはフォントファミリー (システムフォント列挙 `queryLocalFonts` + 持ち込みフォント) / サイズ / 太さ / 色 / 縁取り / 影 / 字間 / 行間 / 揃え / 自動縮小
- **画像**: PNG/JPG/WebPをファイル選択またはドラッグ&ドロップで取り込み → assetsへコピー
- **Undo/Redo**: 操作ごとのJSONスナップショット方式 (最大100段)
- 編集はテンプレート×言語ごと。「JPのレイアウトをENへコピー」ボタンで言語間複製

## 6. 既存機能との統合

| 既存機能 | 変更 |
|---|---|
| 設定タブのSingular項目 (App Token / Sub-Composition / フィールドマッピング) | 削除。代わりに「出力サーバ」設定 (ポート、出力URL一覧表示、コピー用ボタン) |
| 送出ボタン / GPIO / スケジュール / かるた | 変更なし (向き先がローカルエンジンになるだけ) |
| プレビューiframe | ローカル出力URL (`/output/jp?preview=1`) に変更。**インターネット不要になる** |
| 2台運用 | 「Singular送信担当」→「**出力担当PC**」に置き換え。出力サーバは担当PC (vMixが参照するPC、通常ホスト) で起動し、担当でないPCの送出操作は従来どおりコマンド転送。**インターネット自体が不要になる**ため「ホストがオフライン」問題は解消 |
| プロジェクト保存/読込 | テロップデータに加えグラフィックスプロジェクト参照も保存 |

## 7. 実装フェーズ

| Phase | 内容 | ゴール |
|---|---|---|
| **1. 出力基盤** | 出力サーバ / レンダラー / 手書き初期テンプレート / 送出統合 / プレビュー切替 / Singular削除 | vMixで現行運用と同等の送出ができる (デザインはJSON直編集) |
| **2. エディタ基本** | デザインタブ、レイヤー編集 (移動/リサイズ/重ね順)、画像/矩形/テキスト、プロパティ、保存 | 座布団と文字配置をGUIで編集できる |
| **3. アニメーション** | プリセット実装、エディタでの設定UI、試写、stagger | リッチなIN/OUT演出 |
| **4. 磨き込み** | 自動縮小/長体、スナップ/整列、Undo/Redo、フォント持ち込み管理、言語間コピー、エクスポート/インポート | 実運用品質 |

各Phase完了ごとにexeビルドで確認いただく想定。

## 8. 技術的な留意点

- **描画性能**: transform/opacityベースのアニメーションはGPU合成され、vMixのブラウザ入力で60fps動作可能。レイアウト変化 (width等) のアニメは避ける実装とする
- **フォント**: 持ち込みフォント (ttf/otf/woff2) はHTTP配信で出力ページに適用。**フォントのライセンス** (サーバ配信可否) は使用フォントの規約確認が必要。LAN内配信のみ
- **透過**: 出力ページは `background: transparent`。vMix側は「ブラウザ入力」の透過が既定で有効
- **セキュリティ**: 認証なしHTTP。閉域LAN前提 (リモート連携と同様)
- **リージョン競合**: 2台運用時の同時TAKEは出力担当PCの受信順で処理 (最後勝ち)
