# Windows 11 への導入手順

配布物は2種類あります。GitHub Actions の Artifacts (またはリリースページ) からダウンロードできます。

| 配布物 | ファイル | 用途 |
|---|---|---|
| インストーラ版 | `GMO-TelopGo-Setup-X.Y.Z.exe` | 通常のインストール (スタートメニュー登録あり) |
| ポータブル版 | `GMO-TelopGo-X.Y.Z-portable-win.zip` | インストール不要。展開して `GMO TelopGo.exe` を実行 |

本アプリは**コード署名をしていない**ため、Windows 11 では初回実行時にSmartScreen等のブロックが働きます。以下の手順で解除してください。

## インストーラ版が起動しない場合のチェックリスト

### 1. ZIPを完全に展開してから実行する

Actions の Artifact はZIP形式です。**エクスプローラーでZIPを開いた中から直接exeをダブルクリックせず**、
右クリック →「すべて展開」でフォルダに展開してから、展開後のexeを実行してください。

### 2. Mark of the Web (ブロック) の解除

ダウンロードしたファイルには「インターネットから取得した」マークが付き、実行がブロックされることがあります。

1. exe (またはZIP) を右クリック →「プロパティ」
2. 「全般」タブ下部に「セキュリティ: このファイルは他のコンピューターから取得したものです…」の表示がある場合、
   **「許可する」にチェック** → OK
3. ZIPの場合は、ブロック解除してから展開し直す

### 3. SmartScreen の警告画面

実行時に青い画面「**WindowsによってPCが保護されました**」が出た場合:

1. 「**詳細情報**」をクリック
2. 「**実行**」ボタンが表示されるのでクリック

### 4. Microsoft Defender / ウイルス対策ソフト

何も表示されずに起動しない場合、Defenderや社給PCのセキュリティソフトが自動隔離している可能性があります。

- Windows セキュリティ →「ウイルスと脅威の防止」→「保護の履歴」を確認し、隔離されていたら「許可」する
- 組織のポリシーで未署名exeの実行が禁止されている場合は、情報システム部門に許可を依頼するか、ポータブル版を試す

### 5. それでも起動しない場合

- ポータブル版ZIPを展開して `GMO TelopGo.exe` を直接実行する (インストーラを経由しない)
- コマンドプロンプトから exe をフルパスで実行し、エラーメッセージが出るか確認する

## インストール手順 (インストーラ版)

1. `GMO-TelopGo-Setup-X.Y.Z.exe` を実行
2. インストール先を選択 (既定のままでOK) →「インストール」
3. 完了後、スタートメニューまたはデスクトップの「GMO TelopGo」から起動

管理者権限は不要です (ユーザー単位でインストールされます)。

## 運用に必要な追加設定

- **GPIOリモートボタン**: ホストPCに CONTEC「API-DIO(WDM)」ドライバをインストールし、DIO-1616BX-USB を接続
- **リモート連携 (2台運用)**: ホストPC側のWindowsファイアウォールで指定ポート (既定8765/TCP) の受信を許可
  (詳細は docs/remote-operation.md)
